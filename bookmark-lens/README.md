# Bookmark Lens

WXT + React + TypeScript 的 Chrome Manifest V3 可视化书签管理插件。

当前版本安装说明、功能及权限说明以[仓库首页](../README.md)为准。下文保留各开发阶段记录，早期关于工具栏打开侧边栏、不支持删除书签、无网站访问权限或无批量功能的说明已被后续版本替代。

## 安装测试

1. 安装依赖：`pnpm install`。
2. 检查：`pnpm typecheck` 和 `pnpm build`。
3. Chrome 114+ 打开 `chrome://extensions`，启用开发者模式。
4. 选择「加载已解压的扩展程序」，选中本项目 `.output/chrome-mv3` 文件夹。
5. 固定扩展到工具栏，点击 Bookmark Lens 图标打开独立管理页。
6. 开发调试运行 `pnpm dev`，加载 `.output/chrome-mv3-dev`。

## 验证场景

- 与 Chrome 书签管理器核对数量和文件夹层级；创建、改名、移动、删除测试书签，侧边栏应自动更新。
- 搜索标题和 URL，清除搜索，进入多层文件夹并返回；最近收藏按添加时间排序，最多显示 100 项。
- 鼠标停留 300ms 显示预览，固定后移动鼠标不会替换；取消固定后可切换。
- 无截图显示占位；导入 2MB 内 PNG/JPEG/WebP 的真实网站截图，添加描述，重新打开侧边栏检查本地缓存。
- 点击书签在新标签打开；Tab/Enter 操作按钮，列表支持上下方向键；测试 320–500px 宽度。
- 测试空文件夹、无搜索结果，以及普通网页环境下的 API 不可用提示。

## 数据与权限

仅使用 bookmarks.getTree 及书签事件读取真实书签，没有书签写入、删除调用。bookmarks 权限本身允许写入，但本插件不使用该能力。
sidePanel 打开侧边栏，favicon 使用 Chrome 本地 favicon，storage 保存操作状态，IndexedDB 存储截图与描述。无后端、AI、远端截图或网站内容抓取。

Chrome 书签 API 不提供网站截图或描述，因此初始预览为空。截图按规范化 URL（保留路径与查询参数，移除 hash）与书签 ID 列表关联。相同 URL 的书签共享预览，hash 路由页面也共享预览。清除截图会影响该 URL 的全部关联书签，但不修改书签。IndexedDB 写入失败会提示。

列表采用 64px 固定行高虚拟滚动与 overscan；搜索使用 deferred value。筛选遍历本地书签，只有可视行和当前焦点行进入 DOM。


## 右键截图系统

更新后在 chrome://extensions 点击 Bookmark Lens 的重新加载；如果 Chrome 提示新增权限，请启用扩展。

1. 打开需要预览的普通 HTTP/HTTPS 网站，在网页空白处右键，选择「保存当前网页预览」。
2. 只截取当前可见网页区域，不包含整页滚动内容。工具栏 ✓ 表示成功，! 表示失败，悬停图标查看原因；侧边栏同步显示状态。
3. 截图按比例压缩至最多 480px 宽，优先 WebP，不支持时回退 PNG，通过 IndexedDB 本地存储。
4. 再次在相同网站右键保存即可重新截图；预览面板可清除该 URL 截图、固定预览。没有权限的侧边栏不会直接触发截图。
5. 不支持 chrome://、file://、扩展页面及 Chrome 扩展商店。出现截图权限、页面切换或存储失败时，旧缓存保留并显示错误。
6. 截图可能包含当前页面可见的私人信息，仅在本机保存，不上传。只申请 contextMenus + activeTab，不申请所有网站永久访问权限。没有后台批量访问、自动切换标签页或自动截图。

自动测试：`pnpm test`，覆盖 URL 规范化、受限页面、尺寸及 IndexedDB 缓存行为。

手动回归：保存真实网页 → 悬停对应书签 → 核对截图；固定预览后重新保存 → 检查自动更新；关闭重开侧边栏及浏览器 → 检查持久化；清除截图 → 显示占位；未收藏网页保存后再收藏 → 检查 URL 关联；同时确认搜索、文件夹及新标签打开正常。截图时切换标签页应丢弃结果，不能错误关联。受限页面不提供菜单，仍可在侧边栏查看名称和域名。

## V2.0 独立管理页

侧边栏 → 设置 → 打开书签管理页。工具栏点击仍打开侧边栏，不替换 Chrome 新标签页。

- 黑色沉浸式界面、原生文件夹树、桌面三列网格（窄屏两列/一列）、列表切换，视图偏好本地保存。
- 选中文件夹显示其所有子文件夹中的书签；搜索作用于当前范围，支持标题和 URL，⌘/Ctrl+K 聚焦搜索。
- 两个页面复用书签读取、事件同步、Favicon、搜索高亮及 IndexedDB 截图。预览优先级：本地截图 → 网站分享图 → 占位。
- 自动封面第一次需点击卡片「获取封面」并授权该站点。此后授权站点的可见卡片会按需自动读取 Open Graph / Twitter 分享图片。CDN 域名需单独点击授权。分享图不等于网页截图，不保证所有网站提供。
- 不使用后端或第三方截图服务。请求直接发往授权的网站，不携带登录凭据，不跟随重定向；HTTP/HTTPS 跳转、反爬或无分享图会显示失败回退。只按明确授权的来源读取，不自动访问登录态内容。
- 拒绝明显的本地/内网主机名、IP 字面量、带用户名密码的 URL；这不是 DNS 层网络隔离，勿对内部域名授予自动封面权限。
- 并发上限 3，HTML 上限 2MB、图片 4MB，单请求 10 秒超时。成功缓存 7 天，失败冷却 1 小时；用户可手动刷新。截图和分享图分库存储，互不覆盖，来源明确标注。
- 右上角设置可撤销站点授权（保留已有缓存）；详情中可清除网站分享图。清除现有截图功能不删除分享图。
- 管理页使用虚拟网格/列表，避免一次挂载全部书签卡片。所有书签保持只读。

回归测试：打开侧边栏与管理页，核对真实数量和文件夹；搜索、切换视图、进入子文件夹；修改 Chrome 书签后两个页面自动刷新；保存右键截图后两页同步；按站点授权分享图并检查跨域图片授权提示；撤销权限后不再自动请求。首次授权不会在打开管理页时弹出。

## 自定义封面与本地压缩

每张卡片「··· → 上传自定义封面」，或悬停封面点击「更换封面」，也可直接拖入一张 JPG/PNG/WebP。最大输入 30MB / 4800 万像素。仅本地处理，不上传服务器。

原生 createImageBitmap + Canvas.toBlob，初始 WebP 质量 0.8；保持原比例、最大宽 1200px，不放大小图。最多 6 次调整（质量不低于 0.65、尺寸最低为初始输出的 60%），尽量达到 300KB。若小图原文件更小则保留原文件，避免反向增大；未达到目标会明确提示。Toast 展示实际原始大小、保存大小及减少比例。

自定义封面为 IndexedDB Blob，按 bookmarkId 关联，与 URL 截图和分享图分别存储。展示顺序：自定义 → 本地截图 → OG 分享图 → 占位。原生截图更新不覆盖自定义封面；「删除自定义封面」或「恢复自动封面」只删除对应 Blob，立即回退到已有截图/分享图。同 URL 不同书签可以拥有不同自定义封面。Object URL 在更新和组件卸载时释放，替换同一 ID 时覆盖旧记录。

已自动验证存储替换/隔离/删除、优先级、格式限制、缩放、压缩次数与统计、损坏解码回退。Chrome 实测本地测试 PNG 从 6.18MB 压缩至 232.5KB（96.3%），上传立即更新、刷新保留、恢复自动封面回退正常；测试封面已移除。整浏览器重启、跨窗口拖拽及书签移动可按上述流程进一步手动回归。

## 自定义封面编辑器

卡片「··· → 编辑封面」打开居中模态编辑器。可载入已有自定义源图或本地截图/OG 封面。上传、更换和拖入卡片的图片先进入编辑器，只有点击保存才更新缓存。编辑器也支持文件选择、拖拽和 Cmd/Ctrl+V 粘贴图片。

- 16:9 实时预览；拖动或方向键调整位置，滑块/滚轮缩放 1–3 倍；填满卡片限制边界避免露白，完整显示模式居中保留深色留边。
- 重置恢复居中、100% 缩放与填满模式；Esc/取消/关闭时如有修改会确认。原生 dialog 管理模态焦点与 Tab 范围，关闭后恢复之前焦点。
- 保存从尺寸优化但未裁剪的编辑源图生成 960×540 图像，默认 WebP 0.8，最多三档质量（最低 .65），编码失败回退 PNG；目标约 300KB，超出时提示。小源图导出为固定构图可能比原文件大，统计会明确显示增加比例。
- 同一 IndexedDB 记录原子保存最终 Blob、编辑源 Blob、缩放/位置/模式和修改时间。再编辑使用源图，避免对已裁切结果反复裁切。旧版记录没有源图时以现有封面为可编辑源，不能还原此前丢失区域。
- 加载新图片失败保留当前编辑源；写入失败保留旧封面与编辑内容。替换记录和删除封面同时释放不再引用的源图；Object URL 更新/卸载时释放。

自动测试包含横/竖/方/高分辨率构图边界、共享坐标导出、存储重新读取、保存失败保留旧数据、多书签隔离。浏览器完全重启、滚轮/粘贴和完整视觉验收仍需手动回归；此次 Chrome UI 自动验证因工具超时未完成。

## 删除书签

管理页卡片「··· → 删除书签」，二次确认后调用 Chrome bookmarks.remove 删除单个 URL 书签。此操作真实影响 Chrome 书签及其浏览器同步。文件夹不提供此操作。成功后通过现有书签事件刷新管理页与侧边栏，并清理该 ID 的自定义封面；同 URL 的共享截图和分享图保留，避免影响其他书签。早期章节所述“只读”适用于旧版本，目前唯一的书签写操作是用户确认的单个书签删除。

## 批量自动生成封面

管理页顶部「批量生成封面」打开操作面板，可处理当前范围/文件夹（含子文件夹）、勾选书签或全部书签。打开面板后卡片右上角出现勾选框。默认跳过已有截图、分享图和自定义封面；开启刷新选项只更新自动截图，自定义封面始终优先并跳过。

### 权限与运行方式

Chrome captureVisibleTab 的跨站自动截图需要可选 `<all_urls>` 权限，activeTab 只适合用户单次调用。点击开始/继续才申请此权限；面板要求确认会自动访问网站、使用当前 Chrome 会话并截图。权限可在管理页设置中移除。原有按站点授权的 OG 获取仍保留；广泛授权会扩大现有 OG 获取可用范围，完成批量后建议撤销不再需要的广泛权限。

任务使用**独立普通窗口中的扩展任务页**执行，不依赖 Manifest V3 Service Worker 常驻，也不使用 debugger。一次只新建一个 about:blank 标签，记录其 ID 后再导航至目标网站；等待 onUpdated complete（兼容已完成竞态），最多 30 秒，加 1.8 秒渲染等待，再检查登录/验证码等状态并截图。页面长时间加载、重定向至排除页面、用户切换活动标签或截图错误会记录原因并继续下一项。渲染延迟不能保证所有动态网站完全稳定。

截图复用右键保存相同的 captureTab → exportCover → saveScreenshot 流程，960×540 WebP，初始质量 .8、最低 .65，最多三档，尽量 300KB。截图以 Blob 写入原 IndexedDB 截图库，并保留 URL + bookmarkIds 关联；读取兼容旧版 Base64 截图。保存后读回验证 Blob 大小和任务标识，再标成功并关闭临时标签。自定义封面仍单独按书签 ID 存储，绝不覆盖。相同 URL 尽量复用本次或恢复任务已存截图。

### 暂停、停止与恢复

队列及每项 pending/running/success/failed/skipped 状态保存到 chrome.storage.local，不保存图片到 storage。控制指令单独持久化，避免 UI 覆盖执行进度。Web Locks 确保全扩展只运行一个队列。暂停/停止中止当前加载或等待并清理记录的临时标签；已完成项保留，失败项不无限重试。

任务页需要一次性的 chrome.storage.session 启动票据；直接重开任务页不会重新访问网站。浏览器重启、关闭任务页或中断会等待用户明确继续。恢复时 running 还原 pending，不直接当成功；任务标识匹配且已验证的截图可复用。

仅关闭当前浏览器 session、匹配任务 windowId 且在 ownedTabs 中的标签；不关闭 runner 自己或用户原标签。浏览器重启后不信任旧 tab ID，避免误关复用 ID。任务控制页窗口结束后保留供查看，网页临时标签会自动关闭。若系统在创建标签与记录 ID 之间强制终止，可能遗留空白页；宁可不关闭无法证明归属的标签。

### 排除机制

只访问公开形式 HTTPS 地址；默认跳过带查询参数/片段、IP 字面量/本地形式主机、登录/认证/后台/付款等路径。额外排除规则按 URL 子串匹配，每行一条。检查当前页面密码框和常见验证码元素，不绕过验证或登录。URL 检查无法识别所有私有 DNS 与敏感页面，开始前仍应检查所选书签并明确排除。
